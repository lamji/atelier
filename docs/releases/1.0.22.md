- **`atelier-remember` runs inside Atelier.** Pressing Enter on
  `$atelier-remember <fact>` (Codex) or `/atelier-remember <fact>` (Claude)
  no longer starts a model turn: Atelier writes the memory entry itself,
  clears the line, and confirms with a notification. Run as a skill, Codex
  spent the turn searching its tools and MCP resources for a way to write a
  file. `forget <what>` removes the closest entry, and a fact about the same
  subject updates its entry instead of adding a second one.
- **Changes rail drops committed files.** The rail now lists only files git
  still sees as changed. Work committed or reverted earlier no longer stays
  listed next to the session's current changes.
- **Skills name the right tools for each CLI.** The app skills and the
  session hook told the agent to use "file tools", which Codex does not
  have. They now say Read/Glob/Write for Claude and shell commands with
  `apply_patch` for Codex, and never to look for tools through MCP.
