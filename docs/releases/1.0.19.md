- **In-app `document` skill.** Type `/document` in Claude or `$document` in
  Codex to trace a feature end to end; the report is saved in the project
  under `.atelier/doc-agent/`. The skill ships inside Atelier, so nothing is
  installed in your home folder and uninstalling the app removes it.
- **Session documentation button.** A session that has written a report shows
  a book icon next to delete; it opens the report in the main view as rendered
  Markdown, and the close button returns to the terminal.
- **Faster CLI typing.** Keystrokes typed into Codex and Claude are echoed
  without the batching delay, and long scrollback is restored in chunks
  instead of blocking the window.
- **Faster session start.** A shell is warmed up ahead of time, and the pty
  and the session row are created in parallel.
- **Faster session history.** The CLI history scan is cached instead of
  re-walking every stored session.
- **Agents list.** Fixed rows that stayed invisible and left an empty gap in
  the list.
- **Terminal.** Fixed a session opening to a blank pane that could not be
  typed into; the GPU renderer is now opt-in.
- **Git history.** Commits open in a detail pane listing each changed file,
  and a file opens in place with its diff, blame and history.
- **Pull requests.** Reworked requests panel and forge sign-in, and better
  drafted commit messages.
- **Preview.** A preview whose backend is not running now explains what
  failed instead of staying blank, and provider sign-in started from a
  preview completes in the same session.
- **Preview testing.** The agent can replay an API call as the signed-in app
  and run a written test case against the live preview.
- **Agent.** Bug reports must be observed before they are fixed, repeated
  identical lookups are stopped, and a file named in the request is read
  before it is planned or edited.
- **Plans.** A cancelled step no longer stays stuck as the current step.
