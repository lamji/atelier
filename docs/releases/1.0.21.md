- **Workspace memory.** Each workspace now keeps its own memory in
  `.atelier/memory/`, one fact per file: corrections, environment facts,
  what a name means, and how you want work done. Every Claude and Codex
  session Atelier starts reads it at start, after `/new` or `/clear`, on
  resume, and after a compact. Codex's global memory is switched off for
  these sessions, so one project's facts no longer steer a session in
  another.
- **Memory is checked, not just loaded.** Before a session starts, each
  entry is checked against the workspace: the paths it names, and the
  current values of the settings it is about in your `.env` files. Stale
  entries are flagged; passwords and tokens are never copied out.
- **Settings → Memory.** View, edit, add, and delete the workspace's memory
  entries.
- **New `atelier-remember` skill.** `$atelier-remember no Redis locally`
  (or `/atelier-remember` in Claude) saves a fact; `forget …` removes one.
  An existing entry is updated in place, never duplicated.
- **Skills renamed.** `document` is now `atelier-init-feature`,
  `reference-doc` is `atelier-re-init-feature`, and `impact-check` is
  `atelier-impact-check`.
- **Atelier skills in Codex's `$` menu.** The app skills are listed in
  Codex like its own, linked into `~/.codex/skills` (links, not copies).
  Running one no longer hands Codex a path into the Atelier folder, which
  had sent a trace into the wrong repository.
- **Reports stay current after every turn.** Claude and Codex now report
  the end of each turn through their own Stop hook, so report updates no
  longer fire mid-turn. Codex asks once to trust the new hook (`/hooks`).
- **Reports come back after a compact, by themselves.** A session's own
  reports are reloaded automatically after a compact. A new session starts
  clean, with no re-init.
- **Impact check runs only before an edit**, and is no longer offered as a
  skill at session start.
- **Quieter sessions.** Agents no longer open their first reply with an
  "Atelier skills loaded" line or narrate where reports are saved.
- **Connecting screen.** While a workspace's agent starts, the window shows
  one screen with a progress bar and the current step, instead of the
  half-loaded workbench.
- **Settings redesign.** Providers and Skills & Commands are collapsible
  tables; Skills & Commands splits in-app and outside skills, with usage
  and sample prompts; a skill's full text opens inside the Settings window.
- **Reconnect screen.** The "Reconnect CLI" list no longer scrolls sideways,
  shows how long ago each session was used, and makes starting a new
  session the main action.
