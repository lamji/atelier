- **Impact check before and after every edit.** When Claude or Codex edits a
  TypeScript or JavaScript file from Atelier, a tree-sitter check runs on its
  own: it finds the functions the edit touches, every place in the repo that
  calls, imports or references them, and the tests among them, and hands
  that list to the agent before the edit and again after it. It never blocks
  an edit. Ships as the new `impact-check` skill.
- **Skills load at every session start.** A session-start hook tells Claude
  and Codex which Atelier skills they have and which saved reports belong to
  the session, so a compact or resume no longer loses them. Codex asks you
  once to trust the hook in its own review dialog.
- **Answers from evidence.** Every session now starts with an evidence rule:
  before naming a cause or asking you to change data, the agent reads or
  writes the `/document` trace of that flow, checks which branches your
  environment actually runs, and calls anything else unverified.
- **`/document` reports stay current.** When a file a report cites changes,
  Atelier asks the agent at the end of the turn to update that report. A
  report records which config-gated branches run in this environment, and a
  rerun on the same flow rewrites the existing report instead of adding a
  second one.
- **New `reference-doc` skill.** Reloads a session's saved reports into
  context, for example after a compact.
- **Session beside the file explorer.** The Files view shows the active
  session in a side panel, with the session list one click away.
- **Changes rail.** Fixed files with Windows line endings showing every line
  as changed; the per-file counts now match `git diff`. The redundant
  "N files +x −y" total is gone.
- **Codex image attachments.** Running a `$skill` with an image attached no
  longer drops the image.
- **Sessions panel.** Removed a duplicate history button from the side
  session list.
